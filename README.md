# Цитата, пересказ или плагиат?

Учебный модуль с ИИ-помощником «Цитатник». GitHub хранит исходники, Vercel публикует сайт и запускает функцию `/api/chat`.

## Публикация

1. Распакуйте архив. Загрузите его содержимое в корень репозитория GitHub, сохранив папки `api` и `lib`. Проверьте, что `index.html` и `vercel.json` видны на главной странице репозитория. При обновлении старой версии удалите `api/prompt.js`: инструкция теперь в `lib/prompt.js`.
2. В [Vercel](https://vercel.com/dashboard) выберите **Add New → Project → Import** для этого репозитория. Если проект уже подключён к репозиторию, откройте его. Для импорта выберите **Other**, оставьте **Root Directory** на корне репозитория. Команда сборки и выходная папка заданы в `vercel.json`.
3. В разделе **Environment Variables** при импорте или в **Settings → Environment Variables** существующего проекта добавьте переменную `GEMINI_API_KEY`. Вставьте свой ключ из Google AI Studio в поле **Value** и выберите **Production**. Для проверки на Preview добавьте переменную и для **Preview**. Храните значение ключа в Vercel. В GitHub загрузите пустой шаблон `.env.example`.
4. Нажмите **Deploy**. Если переменную добавили после публикации, откройте **Deployments** и выберите **Redeploy** для последней публикации нужного окружения.
5. После статуса **Ready** откройте сайт по адресу Vercel и напишите «Цитатнику»: «Я заменила несколько слов синонимами и поставила ссылку. Это уже пересказ?»

По умолчанию чат использует `gemini-3.1-flash-lite`. У этой модели есть бесплатный лимит. `AI_MODEL` можно указать в Vercel, если для вашего проекта нужна другая модель. Поддержка альтернативных ключей `GROQ_API_KEY` и `ANTHROPIC_API_KEY` сохранена. Если указан ключ Gemini, используется Gemini.

## Если нужен чат по адресу GitHub Pages

Обычная ссылка Vercel готова для сайта и чата. Для отдельной копии на GitHub Pages замените в `index.html` значение `ASSISTANT_URL` на полный адрес функции Vercel, например `https://ваш-проект.vercel.app/api/chat`. В Vercel добавьте `ALLOWED_ORIGIN` со значением домена GitHub Pages без пути, например `https://onamizf.github.io`, и запустите **Redeploy**. При открытии HTML-файла с компьютера сервер чата недоступен.

## Состав проекта

- `index.html` — учебный модуль и окно «Цитатника».
- `api/chat.js` — серверная функция чата.
- `lib/prompt.js` — учебная инструкция для модели.
- `vercel.json` — сборка сайта для Vercel.
- `.env.example` — пустой шаблон переменных окружения.
- `.gitignore` — исключает локальные переменные и результаты сборки.

Адрес отправки итогов в Google Таблицу взят из исходного сайта. Если используете эту функцию после публикации, проверьте появление пробной записи в своей таблице.
